Task Management System

A simple Task Management System built using HTML, CSS, JavaScript, Node.js, Express.js, and SQLite.

Features

* Add new tasks
* View all tasks
* Edit tasks
* Delete tasks
* Mark tasks as Pending or Completed
* Search tasks
* Filter tasks by status
* Dashboard summary of total, pending, and completed tasks
* Save tasks using an SQLite database

Requirements

* Node.js

How to Run

1. Open the project folder.
2. Open the terminal.
3. Install the dependencies:
    npm install
4. Start the server:
    node server.js
5. Open your browser and visit:
    http://localhost:3000

The database file (tasks.db) will be created automatically when the server starts.
